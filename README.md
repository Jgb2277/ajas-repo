EduPath – Personalized Study Planning System

Overview

EduPath is a web-based personalized study guidance system designed to help students manage their studies efficiently.

The system analyzes student performance through quizzes and automatically generates a personalized study timetable along with appropriate learning resources such as PDF notes and YouTube tutorials.

EduPath helps students understand their knowledge level and focus on weak areas to improve learning efficiency.

System Architecture

The EduPath system follows a Client–Server Architecture consisting of:

Frontend (Presentation Layer)
	•	React.js
	•	HTML
	•	CSS

Handles user interaction such as login, quizzes, study plan display, and chat interface.

Backend (Application Layer)
	•	Python
	•	Flask API
	•	Authentication module
	•	Quiz evaluation logic
	•	Timetable generation logic
	•	Resource recommendation system

Database Layer
	•	SQLite Database
	•	SQLAlchemy ORM

Stores:
	•	Users
	•	Subjects
	•	Modules
	•	Quiz questions
	•	Assessment results
	•	Learning resources

System Workflow
	1.	Student registers or logs into the system.
	2.	Student selects a subject and takes an assessment quiz.
	3.	System evaluates quiz answers automatically.
	4.	Based on performance, the system classifies the student into:
	•	Basic
	•	Intermediate
	•	Advanced
	5.	A personalized study timetable is generated.
	6.	The system recommends learning resources like PDF notes and YouTube videos.
	7.	Students can discuss topics using the live chat box.
